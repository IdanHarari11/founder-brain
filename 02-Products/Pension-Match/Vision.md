# Pension Match — Vision

## Mission
SaaS for pension & insurance advisors — show clients their portfolio, compare funds, optimize.

## Revenue Model
B2B SaaS — advisor pays, manages clients.

## Target Market
Israeli pension advisors. Mislaka integration.

## Stage
POC. Production currently shows waitlist only. First paying advisor is the immediate goal.

## Key Integrations
- Mislaka API (Israeli pension clearinghouse)
- data.gov.il (government fund data)
- OpenAI GPT-4o (chat assistant)
- Google Gemini (document extraction)
- Supabase (DB + auth)
